Any function opening the database needs to be in `/database`.

## Commands

- `/load_participants` Fetch participants on Directus and load them into the database.
- `/load_participant_manually` Load a participant manually in the database from their ICeLAN username.
- `/drop_participants` Drops the participants table in the database.
- `/list_participants` Lists all participants in the database.
- `/participant_data` Shows data about a participant in the database.
- `/delete_participant` Deletes a participant from the database.
- `/create_participant` Creates a participant and adds it to the table.
- `/toggle_staff_status` Toggles the staff status of a participant in the database.
